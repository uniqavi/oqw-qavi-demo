## Format

- MP3 preferred (smallest), OGG also works
- Mono is fine for most tracks
- Target ~128kbps — these are looping ambient tracks, no need for studio quality
- Loop seamlessly — trim any silence at the start/end

## How to generate fast

**Suno** (suno.com): prompt template:
> "lo-fi spy synthwave, dingy, slightly comedic, dystopian browser game music,
> instrumental, 90s computer aesthetic, loopable"

**Pixabay Music**: search "spy lofi", "noir lofi", "synthwave dark"

**Uppbeat**: similar tags

Drop the file with the matching name above and reload the game. That's it.
